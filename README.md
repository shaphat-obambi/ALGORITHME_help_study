# ALGORITHME_help_study
Un interpréteur web de pseudo-code en français permettant d'écrire, tester et exécuter des algorithmes directement dans le navigateur. Il intègre un éditeur avec numérotation de lignes, une console interactive pour les entrées/sorties (⁠Lire⁠/⁠Ecrire⁠) et une détection précise des erreurs de syntaxe.
